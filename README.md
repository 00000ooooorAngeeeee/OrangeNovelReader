# 橘子小说 · Orange Novel Reader

一个**纯离线**的 Android 电子书阅读器。导入 EPUB / TXT，解析出章节、目录与插图，自己做排版渲染——不联网、无广告、无账号、无书城。



---

## 功能

### 书架

- **网格 / 列表双视图**，列表显示「已读至第 X 章 · 多久之前」
- **自定义分组**：分组以**文件夹卡片**的形式和书混排（封面取组内前 4 本拼成 2×2）
  - 归组的书只出现在分组里，不再占用书架主列表
  - 分组和书按「最近活跃」统一排序，置顶的书永远在最前
- **长按进入多选**，底部操作条：移动分组 / 置顶 / 重命名 / 详情 / 删除
- **书籍详情**：作者、估算字数、章节数（打开时后台重算）、阅读进度、上次读到、导入时间、文件大小
- 导入 EPUB / TXT（含 TXT 自动转章节），支持换封面、重命名、置顶

### 阅读

- 竖向连续滚动，一章接一章无缝阅读，跨章自动续接
- **底部信息行**（菜单收起时常驻）：`第 X 章/共 N 章` ｜ 章节名（居中） ｜ 已读百分比 ｜ 电量
- **设置面板**
  - 亮度：应用内调节，可「跟随系统」
  - 字号：A- / A+，10–28sp
  - 间距：行距、段距独立调节，带 −/+ 微调；拖动时只更新数值，松手才重排（避免闪烁）
- 长按选中正文可复制

### 目录

- **底部抽屉**，上方露出并压暗正文，点空白处直接关闭
- 书籍卡片 + `详情 / 目录` 两个 Tab 无缝切换（同一抽屉内，不是弹窗）
- 每章显示「约 N 字」，当前章：橙点 + 橙色文字 + 右侧「读到 X%」
- 工具栏：搜索框 + `分卷 ⌄`（跳转到某一卷）/ `精简 ⌄`（隐藏字数行）/ `正序`（点击切倒序）
- **全文搜索**：按内容检索，命中行显示章节名 + 上下文片段并高亮，点击精确跳到命中位置
- 分卷标题、章号全部来自原书目录，缺失时按文件名/顺序兜底

## 技术实现

| 模块 | 说明 |
|---|---|
| 解析 | 自研 EPUB 解析（OPF/NCX/nav 三种目录、spine 顺序、相对路径、HTML 实体）；TXT 按正则切章 |
| 排版 | `ReaderView` 自己用 Canvas 画文本，`ChapterLayout` 预计算每段行/字符位置，支持跨章滚动、字符级定位与选中 |
| 分页 | 连续滚动 + 章节按需加载（前后各预取），跳章时按字符偏移恢复位置 |
| 存储 | SQLite（`modu.db`，v6）：books / groups 两张表；阅读位置记录章号 + 章内字符偏移 + 全书百分比 |
| 依赖 | 仅 appcompat / recyclerview / core，无网络、无图片库、无第三方解析器 |

Java 17 · Gradle 9.5 · minSdk 24 · targetSdk 36

## 目录结构

```
app/src/main/java/com/orange/novel/reader/
├── MainActivity.java          书架：视图切换、分组、多选、详情

```

## ⚠️ 关于包名与签名（改之前务必看）

App 的身份由两样东西决定，**任意一个变了，用户升级就会丢数据**：

| 项目 | 当前值 | 改动后果 |
|---|---|---|
| `applicationId` | `com.modu.reader` | 变成另一个 App，旧数据/书架全部读不到 |
| 签名密钥 | `keystore/modu.jks`（alias `modu`） | 覆盖安装报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，必须先卸载 |
| 数据库文件 | `modu.db` | 改名等于新建空库 |

代码命名空间 `com.orange.novel.reader`（`namespace`）只影响源码与 R 类，不影响身份，可以自由调整。

如果确实要换成全新包名 + 新签名，需要走两步迁移：旧版加「导出书架数据」→ 新版首次启动「导入数据」。

## 已知限制

- 没有浅色/日间主题（仅深色）
- 章节列表无「更新时间」（本地 epub/txt 不带章节时间戳，字数按文件大小估算，标「约」）
- 不支持 PDF / MOBI / AZW3
- 目标设备为现代 Android（自适应图标需 API 26+，24–25 用 PNG 回退）
